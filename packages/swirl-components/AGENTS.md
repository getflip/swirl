# Commands

Run from `packages/swirl-components/`.

```bash
# Scaffold a new component without the prompt
yarn generate component swirl-<name>

# All specs
yarn test

# Specs of one component
npx stencil test --spec -- src/components/<tag>

# Regenerate the committed API files
yarn stencil:build

# Stencil watch + Storybook on http://localhost:6006
yarn start
```

Lint through turbo from the repository root — `yarn lint` here cannot find
eslint:

```bash
yarn turbo run lint --filter=@getflip/swirl-components
```

# Conventions

- Form controls (inputs, buttons, selects, …) use `scoped: true, shadow: false`
  with the comment found in `swirl-checkbox.tsx`. A form control that emits
  `valueChange` also needs an entry in `angularValueAccessorBindings` in
  `stencil.config.ts`.
- Match sibling components: built-in text is a `*Label` prop with an English
  default, ARIA pass-through props are `swirlAria*`, events are camelCase
  without prefix, styles use `var(--s-*)` tokens and the media queries in
  `src/styles/media-queries.css`.

# Docs feed the Swirl MCP

`packages/swirl-ai` builds the MCP's component docs from `<tag>.tsx` and
`<tag>.mdx`. Keep the MDX structure `yarn generate` creates:

- The first paragraph after `# <Title>` is the component description.
- The first `` code={`…`} `` block, under `## Sample usage`, is the usage
  example. Update it when the API changes.
- `## Related components` and `## Accessibility` are copied as-is.

A prop without `?` and without a default is listed as required.

# Generated files

- After changing a component's API (props, events, methods, slots) or adding a
  component, run `yarn stencil:build` and commit the changed
  `src/components.d.ts`, `vscode-data.json` and `custom-elements.manifest.json`.
  Never edit them by hand.
- The React and Angular wrappers (`stencil-generated/`) are generated at build
  time and gitignored. Never edit them.
- `swirl-icon/icons/`, `swirl-symbol/symbols/`, `swirl-emoji/emojis/` and
  `swirl-illustration/illustrations/` are generated by `yarn generate`.
