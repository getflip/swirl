# SwirlPopoverTrigger

The SwirlPopoverTrigger component is used to position and open a referenced
[SwirlPopover component](?path=/docs/components-swirlpopover--docs).

- **[Source Code](https://github.com/flip-corp/swirl/tree/main/packages/swirl-components/src/components/swirl-popover-trigger)**

## Usage

<Canvas of={Stories.SwirlPopoverTrigger}></Canvas>

<Controls of={Stories.SwirlPopoverTrigger} />

ℹ️ **Note:** Referencing a popover via ID only works when the popover is part of
the light DOM. Pass the popover DOM element directly, if the popover is behind a
shadow DOM barrier.

## Sample usage

<Source
  code={`<swirl-popover-trigger swirl-popover="popover">
    <swirl-button label="Trigger element" variant="flat"></swirl-button>
</swirl-popover-trigger>`}
/>

## Related components

- **[swirl-popover](?path=/docs/components-swirlpopover--docs)** (sibling) — The
  popover panel; reference it via the `swirlPopover` prop. The trigger’s default
  slot holds the element that opens the popover.

## Accessibility

### ARIA

| ARIA            | Usage                                                                |
| --------------- | -------------------------------------------------------------------- |
| `aria-controls` | Set on the wrapped trigger element, referencing the popover element. |
| `aria-expanded` | Set on the wrapped trigger element.                                  |
| `aria-haspopup` | Set to "dialog" on the wrapped trigger element.                      |

### Keyboard

| Key                        | Function                                                                    |
| --------------------------- | ---------------------------------------------------------------------------- |
| <kbd>Tab</kbd>              | Moves focus to the trigger, opening the popover when `"focus"` is active.   |
| <kbd>Escape</kbd>           | Closes the popover while the trigger has focus.                            |
| <kbd>Enter</kbd>/<kbd>Space</kbd> | Toggles the popover when `"click"` is active (native button behavior). |

Further keyboard behavior (moving focus within the popover, closing on
outside click) is defined by the associated SwirlPopover.
