## Custom label

Only use the `label` slot when you need custom label markup. The slotted content
replaces the `label` prop visually. Always set the `label` prop as well: it is
used as the accessible name whenever the label is hidden (e.g. `hide-label` with
an icon). Keep the markup simple and only use inline elements.

<Canvas of={Stories.CustomLabel}></Canvas>

<Source
  code={`<swirl-button icon="<swirl-icon-add></swirl-icon-add>" label="Add item">
    <span slot="label">Add <strong>item</strong></span>
</swirl-button>`}
/>

## Disabled with a reason

A `disabled` button can't be hovered or focused, so a wrapping `swirl-tooltip`
never opens. Use `swirl-aria-disabled` instead when users need to know why the
button is disabled. The button looks disabled and ignores clicks, Enter and
Space, but stays in the tab order. Point `swirl-aria-describedby` at a light-DOM
element with the reason for screen readers.

<Canvas of={Stories.AriaDisabled}></Canvas>

<Source
  code={`<swirl-tooltip content="You can't delete the main language.">
  <swirl-button
    label="Delete"
    swirl-aria-describedby="delete-reason"
    swirl-aria-disabled="true"
  ></swirl-button>
</swirl-tooltip>
<swirl-visually-hidden id="delete-reason">
  You can't delete the main language.
</swirl-visually-hidden>`}
/>

## Accessibility

### ARIA

The component follows the
[WAI-ARIA Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

| ARIA               | Usage                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `role="button"`    | Implicit when rendered as <code>&lt;button&gt;</code>; link when <code>href</code> is set. |
| `aria-label`       | Set when the label is hidden (e.g. icon-only) or via <code>swirlAriaLabel</code>.          |
| `aria-disabled`    | Set to <code>true</code> when disabled (button only) or <code>swirlAriaDisabled</code>.    |
| `aria-pressed`     | Set to <code>true</code> when <code>pressed</code> is true (toggle buttons).               |
| `aria-controls`    | Optional; set via <code>swirlAriaControls</code>.                                          |
| `aria-current`     | Optional; set via <code>swirlAriaCurrent</code>.                                           |
| `aria-describedby` | Optional; set via <code>swirlAriaDescribedby</code>.                                       |
| `aria-expanded`    | Optional; set via <code>swirlAriaExpanded</code> (e.g. for popover triggers).              |
| `aria-haspopup`    | Optional; set via <code>swirlAriaHaspopup</code>.                                          |

### Keyboard

| Key              | Action                |
| ---------------- | --------------------- |
| <kbd>ENTER</kbd> | Activates the button. |
| <kbd>SPACE</kbd> | Activates the button. |
