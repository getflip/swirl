# SwirlAvatar

The SwirlAvatar component is used to represent a user via an image, icon or
initials.

- **[Figma Design Specs](https://www.figma.com/file/iRHiAFsHxnzux8gQ9EjlZe/Flip-Components?node-id=34%3A9865)**
- **[Source Code](https://github.com/flip-corp/swirl/tree/main/packages/swirl-components/src/components/swirl-avatar)**

## Usage

<Canvas of={Stories.SwirlAvatar}></Canvas>

<Controls of={Stories.SwirlAvatar} />

The component renders an image if the `src` prop is set and the image is
available. Otherwise, a fallback is rendered according to the following
prioritization.

`initials` ➡ `icon` ➡ `<swirl-icon-person></swirl-icon-person>`

## Accessibility

### ARIA

| ARIA            | Usage                                                                                                                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `role="img"`    | Set on the rendered image, initials or icon so the avatar is announced as an image named by `label`.                                                                                                               |
| `role="button"` | Set on the host of an interactive avatar.                                                                                                                                                                          |
| `aria-label`    | Set to `label`. On an interactive avatar it is set on the host, otherwise on the rendered image, initials or icon.                                                                                                 |
| `aria-hidden`   | Not set by the component. If the avatar is decorative, e.g. it sits next to text that already names the person (list items, chips, menu items), set `aria-hidden="true"` on the `swirl-avatar` element to hide it. |

### Keyboard

Only applicable for interactive avatars:

| Key              | Action                            |
| ---------------- | --------------------------------- |
| <kbd>ENTER</kbd> | Activates the interactive avatar. |
| <kbd>SPACE</kbd> | Activates the interactive avatar. |
