# SwirlRadio

The SwirlRadio component is used as a form control to allow a user to select a
single choice from a list of options. Has to be used in combination with a
[SwirlRadioGroup](?path=/docs/components-swirlradiogroup--docs).

- **[Figma Design Specs](https://www.figma.com/file/iRHiAFsHxnzux8gQ9EjlZe/Flip-Components?node-id=2%3A41)**

## Card with icon

Set `icon` on a radio with `variant="card"` to show a large icon tile above the
label and description. The `icon` prop has no effect on the default variant. The
radio circle stays in the top-right corner, so the selected card does not rely
on the border color alone. To place cards side by side, wrap them in
`swirl-columns` inside the `swirl-radio-group`.

<Canvas of={Stories.SwirlRadioCardWithIcon}></Canvas>

<Source
  code={`
  <swirl-radio-group aria-label="Role scope" value="organization">
    <swirl-columns columns="repeat(2, minmax(0, 1fr))" spacing="16">
      <swirl-radio
        description="View and enable organization-wide permissions here."
        icon="<swirl-icon-groups></swirl-icon-groups>"
        input-id="radio-organization"
        input-name="role-scope"
        label="Organization role"
        value="organization"
        variant="card"
      ></swirl-radio>

        description="Create a role that gives permissions only within the selected user group."
        icon="<swirl-icon-folder-shared></swirl-icon-folder-shared>"

        input-name="role-scope"
        label="User group role"
        value="user-group"

## Accessibility

All radio buttons have to be contained in a
[SwirlRadioGroup](?path=/docs/components-swirlradiogroup--docs).

### ARIA

| ARIA           | Usage                                                                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `role="radio"` |                                                                                                                               |
| `aria-label`   | If no accessible label is provided via the radio's label prop, the `aria-label` or `aria-labelledby` attribute has to be set. |
| `aria-checked` | The radio button gets the `aria-checked` attribute set to `true` in checked state, to `false` in unchecked state.             |

### Keyboard

| Key              | Action                      |
| ---------------- | --------------------------- |
| <kbd>SPACE</kbd> | Activates the radio button. |
