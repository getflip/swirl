# SwirlIllustration

Illustrations are decorative graphics used to support empty states, onboarding
flows, and other messaging throughout the product.

## Accessibility

SwirlIllustration is a presentational graphic component with no ARIA attributes
or keyboard-specific behavior. When an illustration conveys meaning that isn't
otherwise available in text, ensure the surrounding content provides an
accessible description.

### Keyboard

No component-specific keyboard behavior.

## Alternative usage

Each illustration also comes with its own component, used via
`<swirl-illustration-*></swirl-illustration-*>`. E.g.:
